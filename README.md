📊 Customer Segmentation Analysis Using Power BI



📌 Project Overview



This project analyzes customer data to identify meaningful customer segments and discover patterns in customer income and spending behavior.



The project uses Python-based data analysis and Microsoft Power BI to explore customer characteristics and present insights through visualizations.



🎯 Project Objectives



\* Analyze customer demographic and spending patterns.

\* Identify meaningful customer segments.

\* Explore relationships between annual income and spending scores.

\* Present analytical findings through visualizations.

\* Support data-driven marketing and business decisions.



🛠️ Tools and Technologies



\* Microsoft Power BI

\* Python

\* Pandas

\* NumPy

\* Matplotlib

\* Seaborn

\* CSV datasets
